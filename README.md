# Scrollcraft Director

Scrollcraftの設計思想を、API不要・静的HTMLだけで使える設計支援アプリにしたものです。

## 主な機能

- 8問インタビュー
- 8種類のPage Grammar候補
- Feeling Curve / Engineered Peak
- Scroll Score
- Signature Move
- Fingerprint Gate（localStorage）
- Claude Code用プロンプト
- BRIEF.md / design.json 書き出し
- PWA / オフラインmanual

## 公開

GitHub Pagesではリポジトリのルートを公開してください。`index.html` が公開起点です。
